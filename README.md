# 🎓 StudySphere – Smart Student Productivity Dashboard

StudySphere is a web-based student productivity dashboard designed to help students organize their academic activities in one place. It provides simple and effective tools to track attendance, manage assignments, schedule study sessions, save notes, and monitor overall productivity.

## ✨ Features

- 📚 **Attendance Tracker:** Record subject-wise attendance and calculate attendance percentages.
- 📝 **Assignment Manager:** Add assignments, set deadlines, mark tasks as completed, and delete them.
- 📅 **Study Planner:** Organize study topics with preferred time slots.
- ⏱️ **Pomodoro Timer:** Use a 25-minute focus timer to improve study concentration.
- 📒 **Quick Notes:** Write and save important study notes.
- 📊 **Productivity Overview:** Visualize attendance and assignment progress through charts.
- 💾 **Local Storage:** Save attendance, assignments, study schedules, and notes directly in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Chart.js
- Font Awesome
- Browser LocalStorage

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start managing your academic activities!

## 🎯 Objective

The main objective of StudySphere is to provide students with a simple, user-friendly platform to manage their academic responsibilities, maintain attendance records, organize study schedules, and track productivity efficiently.
